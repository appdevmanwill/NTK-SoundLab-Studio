# SoundLab browser assets

This directory is the PHP application's web root. It contains the shared studio assets and Laravel's public entry point.

Edit the frontend in `working/` at the repository root, then regenerate the staged copies when preparing a package. The PHP entry views also need to match the shared studio page.
